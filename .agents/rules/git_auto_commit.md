# Git Backup Rule (Project Level)

編集時には必ず https://github.com/evitadesignart/bkup 等の対応するリポジトリに commit および push すること。
ファイル破損や文字化けを防ぐため、編集前と編集後の両方でバックアップとしてプッシュすることが推奨される。

**【厳格なプッシュルール】**
バックアップ（git commit / push）を実行する際は、GitHub上で正しいフォルダ構造（例：\horo/...や tane/...\）を維持するため、必ず**1階層上の親フォルダ（プロジェクトのルートフォルダ、例： \E:\★R8個人サイト\★fortune\ や \E:\★R8個人サイト\★tane\）**をカレントディレクトリとして指定し、そこから全体をプッシュすること。

決して \horo\ などの内部サブフォルダをルートとしてプッシュを行わないこと。
